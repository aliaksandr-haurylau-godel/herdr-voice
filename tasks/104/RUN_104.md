  the microphone only. It keeps working through the same chooser function the settings popup
  uses, so the fix for #46 applies to both.

  place of the owner's wording "herdr voice: settings"; it is one string in one place.

### S4 code review (fresh reviewer, diff `bb27d71..5893278`)

Four Important and eleven Minor findings, no Critical. Re-graded by what a person gets, not by
the label, and fixed in one pass, each with a test that failed first; suite 968 of 968, clippy,
fmt, manifest and the Windows dead-code check clean afterwards.

Fixed:
- A token was printed when `config.toml` did not load: the parser's own text quotes the
  offending line, so `token = some-plain-value` (quotes forgotten) or `token = 12345` came back
  on the screen, in the sections menu, the speech-model flow, the writer's refusal and, through
  the daemon's reply, in the reload message. `config::parse_failure` now gives the position and
  the parser's message and, for a line that sets a token, the position only; `load` and the
  writer use it (`a_file_that_does_not_load_never_has_its_token_printed_in_the_reason` and
  `a_file_that_already_fails_to_load_does_not_have_its_token_printed_when_an_edit_is_refused`).
- Installing the configured model that was missing ended without a word about a restart; it
  now says the daemon loaded its engine before the model was there.
- The shipped default (`command`, empty) was told it "brings its own model"; it is now told no
  speech engine is set up yet and to run `herdr-voice doctor`. The advice for a command that uses
  `{model}` now includes setting `[stt] model` in the file, and AC-29 says so.
- `inf`, `nan` and numbers that overflow the `f32` key are refused; two double quotes empty a
  text key; the microphone list says how to return to the system default; the rewrite model
  for an engine other than `http` is said not to be used yet.
- A refusal says to check the typed value first; a file that parses but does not load is shown
  as defaults like the note says; the end of the input inside a section no longer draws the
  sections again.
- The model-list request follows no redirect (a 3xx answer is a failure that names its status),
  takes the token out of anything the server says back, and drops control characters from the
  names it sends.
- `docs/design.md` named the removed `mic` action; `REWRITE_ENGINES` has a test that the engine
  resolves exactly those names.

Final: Ruling: `Glance::Whole` checks the size of a model's files and not their digest, so a
model of the right size with wrong bytes is reported as installed and `[stt] model` is written
without the full check — the listing is size-only by design (hashing six multi-gigabyte files
to draw a list would take a minute), `doctor` reports a model that fails the full check, and
`install` runs it after every download — cost if wrong: one take that reports "recognition
unavailable" until the model is fetched again.
Final: Ruling: a byte that is not UTF-8 on the terminal ends the popup like the end of the input
does (`read_line` returns an error) — a terminal does not send one, and the message names what
to do — cost if wrong: a popup that closes on a stray byte.
