# AC_86

Acceptance criteria for issue #86, read from GitHub.

## As is

`setup` asks one question when it has something to write: `... in the file named
above? [y/N] then Enter: `. The answer comes from `main` in `src/setup.rs`, a
closure that calls `read_line` on standard input and returns `Some(line)`.
`read_line` returns `Ok(0)` at end of file, so the closure returns `Some("")`.
`run` takes `answer().unwrap_or_default()`, which does not match `y` or `yes`, and
prints `nothing was changed.` and returns 0. A run that was answered `n` and a run
that was never answered produce the same output and the same exit code.

The branch that asks is chosen by `std::io::stdin().is_terminal()`. A command runner
that gives a child a terminal for output but does not forward keystrokes makes that
true while every read returns end of file.

## To be

1. A run whose answer ends at end of file (or cannot be read) prints a message that
   says the question could not be answered, that nothing was changed, and what to do:
   run `herdr-voice setup` in a terminal that forwards keystrokes.
2. That message is different from the one printed for a declined offer.
3. A run answered `n`, `no`, empty or anything else keeps printing `nothing was
   changed.` and exiting 0, unchanged.
4. Nothing is written when the answer is missing.
5. The exit code for the unanswered run is stated in `DESIGN_86.md` with its reason.
6. The legacy report (`report_legacy`) is still printed after either message.

## Requirements

- R1. `run` distinguishes `answer()` returning `None` from `Some("n")`.
- R2. The closure in `main` returns `None` when the read returns zero bytes or fails.
- R3. A unit test: `None` takes a different path from `Some("n\n")` (output and exit code).
- R4. A unit test on the reading function: empty input gives `None`; `"\n"` gives
  `Some("\n")`; a last line without a newline gives `Some` of that line.
- R5. S5: the built binary run with standard input a terminal and the first read at end
  of file prints the new message; recorded in `docs/evidence.md` with the platform.

## Out of bounds

- Guessing an answer when none arrives.
- The `is_terminal` check that chooses the branch.
- The question's wording, and the non-interactive branch that opens the pane.
